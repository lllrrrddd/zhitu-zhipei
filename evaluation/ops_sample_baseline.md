# 运维简历样本试测基线

## 文件检查

- PDF 共 2 页，可以提取文字。
- Word 文本可提取，主体经历与 PDF 对应。
- 用现有应用的 `extract_document_text` 读取原件，PDF 提取 2629 字符，Word 提取 3039 字符，均无解析警告；两者均保留 EDR、Docker、Python、2026 等检查词。
- 两份文件均含个人联系方式，试测时使用 `samples/derived/ops_resume_deidentified.txt`。

## 人工预期

使用 `samples/derived/ops_jobs.md` 中的三条虚构 JD。预期排序是 O01、O02、O03。O03 的学历和年限要求应被识别为硬性差距；O02 的值班告警与监控平台经验应标为证据不足。

## 诊断预期

1. 提醒核对 EDR 项目与同一时间段实习的关系，避免重复计算工作年限。
2. 对“大幅提升”“保障稳定”等缺少验证依据的表述提出具体化建议，不编造指标。
3. 保留本科身份，不改写成研究生背景。
4. 对“2 小时到 20 分钟”的成果要求本人确认计算口径后再用于对外简历。

这是一份人工基线。系统结果和用户反馈尚待记录。
