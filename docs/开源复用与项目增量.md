# 职途智配开源复用与项目增量

## 来源

本项目以 [ResumeForge](https://github.com/magicapple123/ResumeForge) 的 `main` 分支快照为基础，获取时记录的提交为 `1788e531f78901d549fa7d572bc8b2fc89314232`。源码压缩包不带 Git 历史，来源记录见 `docs/source-selection.md`。原项目采用 Apache-2.0；其 `LICENSE`、版权声明和源文件中的许可标记须在参赛版本中保留。参赛名称“职途智配”用于本团队的应用场景和增量功能，不把原项目全部功能归为团队原创。

## 复用的基础能力

原项目已经提供 FastAPI + React 工作台、个人资料和简历管理、岗位录入、岗位匹配与横向对比、通用简历质量检查、模拟面试、本地数据存储、模型配置和测试体系。演示这些模块时应说明其开源来源；原项目 README 的截图和指标不等同于本项目的实测证据。

## 仍属计划的能力

现有候选岗位可选用本地 Embedding 重排，但还没有全量向量召回或 LLM 证据重排。研究生科研能力画像的逐字段可靠确认、对任意用户岗位 JD 的可靠自动抽取与核验、材料 OCR 核验、教师群体看板、50+ 简历效果验证和真实用户试用尚不能作为已完成成果。岗位数量已扩大，但规模不等于推荐准确率。实验台现可生成待核对的本地草稿并重排，不能把它描述为任意 JD 的可靠自动分析。技术说明书中的 PostgreSQL、pgvector、PaddleOCR 与 Docker Compose 是建议选型，当前基础应用的实际实现和部署应单独如实说明。
