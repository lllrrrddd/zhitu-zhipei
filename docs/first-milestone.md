# 第一阶段验收

## 要回答的问题

面对同一份研究生简历，系统能否把更合适的岗位排在前面，并用简历与 JD 中可核对的内容解释原因。

## 范围

1. 准备一份虚构研究生简历和三条公开或虚构的岗位 JD。
2. 在现有系统中导入资料和岗位，生成并检查匹配结果。
3. 检查每条匹配理由有无原文依据，记录错误判断。
4. 生成一条可核对的简历诊断建议。
5. 用两到三名目标用户试测，再决定面试模块的调整。

## 完成标准

- 用户可以从输入简历和 JD 连续操作到查看匹配结果。
- 至少三条岗位结果可复现，且能解释排序差异。
- 修改建议引用原文，不补造经历、数字或成果。
- 记录用户是否认可推荐及其理由，保留至少一个错误案例。

## 待团队提供

- 实际团队成员和每人可投入时间。
- 比赛提交及答辩日期。
- 研究生志愿者同意使用的脱敏简历与真实岗位 JD。
- 可使用的大模型服务或本地模型条件。
