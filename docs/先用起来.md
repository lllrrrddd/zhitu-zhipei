# 职途智配：先用起来

## 打开演示

在 PowerShell 运行：

```powershell
& 'D:\LLMOCR简历\start-demo.ps1'
```

打开 `http://127.0.0.1:5173/graduate`。如提示已有演示进程，直接打开这个地址。结束时运行 `& 'D:\LLMOCR简历\stop-demo.ps1'`。

## 三分钟试一遍

1. 保持默认的“计算机硕士样本”，核对画像后勾选确认，点“根据确认的信息排序”。先看“方向匹配”和“需要补充或核对”两组，展开一条岗位的来源、能力证据与简历建议。点击岗位名称或“前往企业官网招聘页”会在新标签页打开企业招聘原文。当前默认集有 20 个官网岗位：昂瑞微 7 个、腾讯 2 个、华为 11 个。华为链接含具体岗位方向编号；未写明学历门槛的方向仍需在官网核实。打开后还要核实申请入口是否开放。
2. “岗位广场”在隔离演示数据中会按岗位编号增量加入这些官网岗位。点击岗位名称打开详情，再点“前往企业官网招聘页”直接查看招聘原文。岗位状态先标“待核实”；“投递台”只处理受支持的招聘网站，不负责企业官网投递。企业官网申请由本人在官网完成。
3. 在“录入自己的岗位”中粘贴一段招聘原文，点“本地识别为待核对草稿”。逐项检查单位、岗位、学历、专业、技能和 HTTPS 来源，勾选确认后加入比较，再重新排序。展开“逐项核对岗位条件与简历证据”检查依据。自录岗位可点“保存到岗位库”，再从详情继续分析或制作岗位简历；未确认开放的岗位会标“待核实”。
4. 想从简历开始：到“我的资料”点“导入简历并识别”，可粘贴 `samples/fictional_graduate_resume.txt` 的内容；校对识别结果，确认填入并保存。回到“智能选岗”点“加载我的资料”，核对画像后再排序。本机 CPU 模型试测这份文本约需 90 秒，期间请等待识别完成；不配置模型时可由现有本地规则生成草稿。“简历中心”存放已生成或手写的岗位版简历；只导入个人资料不会自动生成一份岗位版简历。
5. 看到有事实依据的简历建议后，可填写本人贡献、方法及可证明结果，确认后生成可复制的科研/项目经历草稿。也可填写采纳或拒绝的理由并下载本地反馈 JSON；文件是否交给项目组由你决定。

这份虚构简历只供试用。识别结果和岗位条件都需要人工核对；“方向匹配”表示当前资料有相关证据，不代表岗位仍开放或保证录用。
