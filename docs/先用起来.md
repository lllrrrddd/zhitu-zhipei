# 职途智配：先用起来

## 打开演示

在 PowerShell 运行：

```powershell
& 'D:\LLMOCR简历\start-demo.ps1'
```

打开 `http://127.0.0.1:5173/graduate`。如提示已有演示进程，直接打开这个地址。结束时运行 `& 'D:\LLMOCR简历\stop-demo.ps1'`。

## 三分钟试一遍

1. 保持默认的“计算机硕士样本”，核对画像后勾选确认，点“根据确认的信息排序”。先看“方向匹配”和“需要补充或核对”两组，展开一条岗位的来源、能力证据与简历建议。
2. 在“录入自己的岗位”中粘贴一段招聘原文，点“本地识别为待核对草稿”。逐项检查单位、岗位、学历、专业、技能和 HTTPS 来源，勾选确认后加入比较，再重新排序。演示岗位开放状态尚未实时核实。
3. 想从简历开始：到“我的资料”点“导入简历并识别”，可粘贴 `samples/fictional_graduate_resume.txt` 的内容；校对识别结果，确认填入并保存。回到“研究生选岗”点“加载我的资料”，核对画像后再排序。本机 CPU 模型试测这份文本约需 90 秒，期间请等待识别完成；不配置模型时可由现有本地规则生成草稿。
4. 看到有事实依据的简历建议后，可填写采纳或拒绝的理由并下载本地反馈 JSON；文件是否交给项目组由你决定。

这份虚构简历只供试用。识别结果和岗位条件都需要人工核对；“方向匹配”表示当前资料有相关证据，不代表岗位仍开放或保证录用。

2026 年 11 月 5 日验证：四条研究生选岗浏览器流程通过；应用接口对这份虚构简历返回姓名、1 条教育、2 个项目、6 项技能。它只证明操作链路可运行，不是任意简历的识别准确率。
