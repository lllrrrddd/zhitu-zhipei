# 职途智配：先用起来

## 启动

在 PowerShell 运行：

```powershell
& 'D:\LLMOCR简历\start-demo.ps1'
```

打开 `http://127.0.0.1:5173/`。已有演示进程时直接打开地址。结束时运行 `& 'D:\LLMOCR简历\stop-demo.ps1'`。

## 三分钟走一遍

1. 在首页上传 PDF/DOCX 简历、粘贴文字，或点“用示例试试”。**每导入一份简历会新建一份“匹配档案”**（档案只存在本机浏览器）：一个人有多个方向、或者临时帮同学匹一次，在“匹配档案”条里切换即可，不会覆盖“我的资料”里那份用来生成简历的画像。示例为虚构人物。上传后先校对学历、毕业年、专业、目标岗位、城市、技能和项目经历；本地规则可能漏读或读错。单份文件上限 10 MB（图片截图仍为 2 MB），扫描件如没有可提取的文字需先转成可读文字。
2. 点“确认并找岗位”。结果会列出推荐依据、需要核对的条件、要求片段和“打开招聘原文”。招聘信息从企业公开来源读取，不把虚构 JD 混入实时结果；一个人可能只获得少量结果，也可能没有结果。

   在结果里点“收藏岗位”时，会连同**这次用的是哪份匹配档案、打了几分**一起记在本机；到“收藏夹”那条岗位旁就能看到“运维方向 · 87 分”。换成另一份档案匹配同一个岗位后，若分数更高会直接点名“更匹配：测试方向 91 分”——这就是“一个人多个方向，哪个更有胜算”的答案。

   卡片上的分数下方有一行“较上次 ±N 分”，展开“匹配历史”能看到最近几次记录（时间、分数、命中几项技能）。历史同样只存在这台浏览器：改完简历或补了技能再匹配一次，就能看到分数是涨了还是掉了；同一个岗位换一份“匹配档案”匹配时，两者的分数不会混在一起比。
3. 点“打开招聘原文”到企业的具体招聘详情，核对岗位是否仍开放、学历、毕业届别、工作年限、地点以及申请入口。点“保存岗位”可放进“已保存岗位”，然后在既有岗位详情里继续做简历分析。
4. “招聘来源”显示本次读到的条数、每个来源的数量、最近核对时间和状态。点“刷新岗位”主动同步；停留页面时每 30 分钟自动检查。若来源失败，旧记录会标为“上次记录”。“核对岗位链接”只识别已接入来源的岗位 ID；未查到也不等于岗位不存在，可能不在当前收录范围内。
5. 展开一条岗位的“对这条岗位改进简历”，先点“诊断这份简历”：给出诊断分、关键词覆盖（技能栏已有／只在经历里提到／还没提）、成果量化、行动力、材料完整四项，以及逐条指回你自己原文的问题。诊断只做规则检查，不判断能否通过某家公司的 ATS，也不替你写句子。要改哪句，用下面的表达建议：填写本人贡献、使用的方法和可证明结果，勾选事实确认后生成表达。可采纳到本次求职画像并重新排序，也可暂不采纳；原始简历文件不会被改写。点“开始五轮面试”会用当前画像和该岗位招聘要求开一场固定五轮的文字面试。完成后看报告，还可对报告追问。面试内容由当前配置的模型处理，若配置外部模型，资料会发送到该服务商。
6. 点结果上方“继续核对就业材料”，上传证书等 PDF、DOCX、PNG 或 JPEG。文字版文档在本机提取；图片和扫描 PDF 必须明确勾选模型抄录。结果列出识别文字、字段字样是否出现及原文片段。逐项对照原件后选择一致或不一致，可下载本次核对记录。**系统不判断证件真伪**，本步骤不保存材料原件；记录仅在主动下载时写到本机。

## 来源范围与真实性

当前接入 [华为校招](https://career.huawei.com/cn/campus-recruitment-job-list)的部分应届岗位方向、[腾讯招聘](https://careers.tencent.com/search.html)中运维相关职位、[博世公开招聘页](https://jobs.smartrecruiters.com/BoschGroup)的 JMP 项目、[先正达集团公开招聘页](https://jobs.smartrecruiters.com/SyngentaGroup)的中国岗位，以及乐斯福、艾利丹尼森、尼尔森IQ、欧陆科技、维多集团五家企业在 SmartRecruiters 上标注初级职级的中国岗位和[伊利 2027 届校招研发](https://yili.hotjob.cn/wt/yili/web/templet1000/index/corpwebPosition1000yili!gotoPostListForAjax?brandCode=1&recruitType=1&showComp=true)。来源及核验样例见[企业公开岗位来源核验](../source/ResumeForge/docs/official-job-sources.md)。

后台用公开职位列表上的编号读取对应详情，并核对原文链接；伊利岗位还核对详情页和截止日期。腾讯运维查询只读取第一页，华为按岗位类别抽样，其他来源按明确范围查询。界面上的总数是这些范围在最近一次同步时的记录数，不是全网岗位量，也不是保证仍开放的职位数。有明确工作经验要求的职位会保留核对提示，毕业生应以原招聘页为准。

用户简历由本机服务提取，并由本人校对。匹配时只把非身份字段交给本机排序；姓名、联系方式不进入公开招聘来源查询。本机 Ollama 若已安装 `qwen3-embedding:0.6b`，可对候选岗位做向量重排；没有模型也能用规则排序。当前尚无全量语义召回或推荐准确率证明。

## 比赛功能进度

首页现可演示“简历导入 → 确认 → 岗位发现 → 理由与原文 → 采纳一条有事实依据的表达 → 五轮文字面试与报告 → 材料文字核对”。面试引擎、报告、追问、文档提取及图片抄录沿用 ResumeForge 底座；本项目增加从真实招聘结果到这些能力的上下文衔接和人审边界。旧版 `/graduate/advanced` 保留手工招聘条件实验。教师群体看板、独立样本的识别与推荐准确率、材料 OCR 准确率、真实用户试用仍需完成。当前招聘数量不能代替这些效果验证。
