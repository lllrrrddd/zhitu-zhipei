# 试测资料

这里只放虚构样本，或取得本人同意后去掉姓名、电话、邮箱、学号等识别信息的资料。公开岗位 JD 请保留来源链接和采集日期。

第一轮需要 1 份简历和 3 条岗位 JD。先人工写下预期排序及理由，再运行系统，便于识别真实错误。

`private/` 保存用户提供的原始 PDF 和 Word，仅供本机解析；`derived/` 放去标识化试测文本及配套虚构岗位。运维样本为本科毕业生，适合检验解析与岗位匹配边界；研究生目标场景仍需研究生样本。

公开合成版式样本放在 `../source/SyntheticResumeData/`，只取了六份 PDF 及对应标注，并保留原仓库 README 和 Apache-2.0 许可证。试测方法与结果见 `../evaluation/public_resume_probe_2026-11-04.md`。这些样本用于识别鲁棒性测试，不能代表真实研究生求职人群。
