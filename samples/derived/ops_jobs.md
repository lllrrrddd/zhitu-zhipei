# 运维样本配套虚构岗位

这些 JD 专用于测试排序解释，不代表真实招聘岗位。测试前的人工预期顺序为 O01、O02、O03。

## O01 初级安全运维工程师

接受计算机相关专业 2026 届本科毕业生。负责 Linux 与 Windows 主机日常运维、终端安全产品部署、故障处理、Docker 容器维护和运维文档编写。Python 脚本能力为加分项。

人工依据：学历、届别、EDR 运维、系统部署、故障处理和 Docker 都有简历依据。

## O02 初级平台运维工程师

接受计算机相关专业本科毕业生。负责 Linux 服务器巡检、Nginx 配置、MySQL 维护和脚本自动化。要求能处理值班告警，熟悉监控平台。

人工依据：系统、Nginx、MySQL 与 Python 有依据；值班告警和监控平台未在简历中明确出现，应列为待确认。

## O03 高级云原生平台工程师

要求硕士学历、5 年以上生产环境经验，熟悉 Kubernetes 集群架构、服务网格、分布式存储和大规模故障应急。

人工依据：样本为本科应届毕业生，不满足学历与工作年限要求。简历虽然提及 Kubernetes，但没有集群架构和大规模生产运维的明确证据。
